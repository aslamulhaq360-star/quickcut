# QuickCut • সম্পূর্ণ অফলাইন মোবাইল ভিডিও এডিটর (Personal Offline PWA)

**QuickCut** একটি সম্পূর্ণ ক্লায়েন্ট-সাইড (Client-Side), প্রাইভেট ও অফলাইন ভিডিও এডিটর।
এটি আপনার নিজস্ব অ্যান্ড্রয়েড (Android) ফোনে কোনো ক্লাউড সার্ভার, ব্যাকএন্ড, ডেটাবেস বা লগইন ছাড়াই কাজ করে।

---

## 📱 আপনার নিজস্ব অ্যান্ড্রয়েড ফোনে ব্যবহারের ৩টি সহজ উপায়:

### উপায় ১: সরাসরি ফোনে ফাইলটি খুলে ব্যবহার (Direct File / Offline Browser)
1. এই ZIP ফাইলের সব ফাইল আনজিপ করে আপনার ফোনের যেকোনো ফোল্ডারে (যেমন `Download/QuickCut`) রাখুন।
2. আপনার ফোনের যেকোনো আধুনিক ব্রাউজারে (যেমন Google Chrome, Kiwi Browser, Samsung Internet) গিয়ে `index.html` ফাইলটি চালু করুন।
3. কোনো ইন্টারনেট কানেকশন ছাড়াই যেকোনো MP4, WebM বা MOV ভিডিও ট্রিম, কাট ও স্প্লিট করতে পারবেন।

### উপায় ২: ওয়াই-ফাই বা হটস্পটের মাধ্যমে ফোনের হোমস্ক্রিনে PWA ইনস্টল
1. একই লোকাল ওয়াই-ফাই নেটওয়ার্কে আপনার কম্পিউটার বা ল্যাপটপে এই ফোল্ডারে টার্মিনাল খুলে চালান:
   ```bash
   npx serve .
   # অথবা
   python3 -m http.server 8000
   ```
2. আপনার ফোনে ব্রাউজার খুলে কম্পিউটারের লোকাল আইপি টাইপ করুন (যেমন `http://192.168.1.5:8000`)।
3. স্ক্রিনে আসা **"QuickCut ইনস্টল করুন / Install"** বোতাম চাপুন বা ব্রাউজার মেনু থেকে **"Add to Home Screen / Install app"** চাপুন।
4. ইনস্টল হয়ে গেলে অ্যাপটি ফোনের অ্যাপ ড্রয়ারে চলে আসবে এবং এরপর সম্পূর্ণ অফলাইনে কাজ করবে।

### উপায় ৩: অ্যান্ড্রয়েড স্টুডিও APK আকারে ইনস্টল (Zero-Server Native WebView)
- এই প্রজেক্টের রুট ডিরেক্টরিতে সম্পূর্ণ অ্যান্ড্রয়েড স্টুডিও সোর্স কোড অন্তর্ভুক্ত রয়েছে (`app/src/main/...`)।
- `gradle assembleDebug` কমান্ড দিলে একটি সেলফ-কনটেইন্ড অফলাইন APK তৈরি হয় যা কোনো বাহ্যিক নেটওয়ার্ক কল ছাড়াই কাজ করে।

## 🔒 গোপনীয়তা ও পারফরম্যান্স (100% Private & Local):
- **কোনো ক্লাউড নেই:** ভিডিও কখনোই কোনো দূরবর্তী সার্ভারে আপলোড হয় না।
- **ডিভাইস প্রসেসিং:** সমস্ত ট্রিম, স্প্লিট এবং কাট ব্রাউজারের স্থানীয় হার্ডওয়্যারে (Local MediaRecorder API) সম্পন্ন হয়।
- **কোনো খরচ বা সাবস্ক্রিপশন নেই:** সম্পূর্ণ ব্যক্তিগত ব্যবহারের জন্য প্রস্তুত।
